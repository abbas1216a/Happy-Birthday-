# Happy Birthday Page

This folder contains a special birthday greeting page built with HTML, CSS, and JavaScript.

## Files

- `index.html` — birthday greeting page
- `style.css` — styling and page layout
- `script.js` — button interaction for revealing the wish

## How to use

1. Open `happy-birthday/index.html` in your browser.
2. Click the **Show Your Wish** button.

## Notes

- This README is specific to the birthday page only.
- The rest of the repository contains separate demo pages and a school management interface.
